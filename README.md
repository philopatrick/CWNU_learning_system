# CWNU Learning System

CWNU learning system monorepo for international students, teachers, and admins.

## Planned Scope

- attendance management
- homework publishing and submission
- simple course and enrollment management
- code playgrounds for HTML, CSS, JavaScript, C++, Java, and Kotlin
- AI assistance for syntax help, compiler error explanation, and guided learning

## Apps

- `apps/backend`: backend API and domain modules
- `apps/web`: web application
- `packages/shared`: shared contracts and types

## Notes

This repository is being bootstrapped in phases. The initial implementation focuses on structure, domain contracts, backend module scaffolding, and web UX scaffolding.
