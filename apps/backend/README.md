# Backend

TypeScript backend skeleton for the CWNU learning system.

## Scope

- auth and session flow
- users and roles
- courses and enrollment
- attendance tracking
- homework publishing and submission
- playground metadata and AI assistance contracts

## Notes

This backend is intentionally framework-agnostic for now. The module layout follows a NestJS-style structure, but the runtime is a small internal HTTP skeleton so the project can grow without locking into a dependency choice too early.
