# Roadmap

## Phase 1

- monorepo bootstrap
- MongoDB local development setup
- shared contracts
- backend skeleton
- web skeleton

## Phase 2

- persistence layer
- authentication
- attendance APIs and UI
- homework APIs and UI

## Phase 3

- playground authoring and exercise catalog
- browser playground for HTML, CSS, and JavaScript
- AI teaching assistant integration

## Phase 4

- sandboxed runner service for C++, Java, and Kotlin
- automated test-case execution
- richer teacher grading and analytics

## Phase 5

- mobile app for student and teacher daily workflows
- push notifications
- attendance QR or geo-based extensions if needed
